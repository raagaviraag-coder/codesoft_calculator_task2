# Simple Calculator using Python

## Introduction
The Simple Calculator is a beginner-friendly Python project developed to perform basic arithmetic operations such as addition, subtraction, multiplication, and division. This project is designed as a command-line application where users can enter two numbers and choose an operation to get the desired result.

The main objective of this project is to understand the fundamentals of Python programming, including user input handling, conditional statements, arithmetic operations, and error handling.

---

# Features
- Perform Addition
- Perform Subtraction
- Perform Multiplication
- Perform Division
- Handles division by zero errors
- Easy-to-use command-line interface
- Beginner-friendly Python project

---

# Technologies Used
- Python 3
- Command Prompt / Terminal
- Any Python IDE (VS Code, PyCharm, IDLE, etc.)

The objective of this project is to:

---

# How the Calculator Works
1. The program asks the user to enter the first number.
2. The user enters the second number.
3. A menu of operations is displayed.
4. The user selects an operation.
5. The calculator processes the input.
6. The result is displayed on the screen.
